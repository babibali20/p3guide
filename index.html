Project 3 — Linux Boot Steps

Reference sheet — readable from Ubuntu's own browser once you're connected to WiFi
Goal of this page: get the iPad from DFU mode into a "PongoOS" shell for the first time, using the real palera1n tool on real (non-virtual) Linux. That's the only thing this covers. Uploading the kernel/module is a separate step after this is confirmed working.

1 Boot into the USB

  1. Start menu → Power → Shut down (full shutdown, not restart)
  2. Press the power button
  3. The instant it powers on, tap Esc repeatedly (HP Startup Menu)
  4. Press F9 for Boot Device Options
  5. Arrow keys → select the USB drive → Enter
  6. At Ubuntu's screen, choose "Try Ubuntu" — never "Install Ubuntu"

2 Connect to WiFi

  1. Click the network icon, top-right of the screen
  2. Select your WiFi network, enter the password, connect

3 Open a Terminal

  1. Click "Activities" (top-left) or the search icon
  2. Type terminal, open it

4 Download and verify the exact tool

Paste each line, press Enter after each:

cd ~/Desktop
wget https://github.com/palera1n/palera1n/releases/download/v2.0.0-beta.9/palera1n-linux-x86_64
chmod +x palera1n-linux-x86_64
sha256sum palera1n-linux-x86_64

Output must match exactly:

5b6dec3a7ee15b14e989466a098d02edeb8455070009ffaa228caf2b3298dbd8

If it does not match exactly — stop and report back before continuing.

5 iPad into DFU mode

  1. Plug the iPad into the laptop via USB
  2. Hold Power + Home together for exactly 8 seconds
  3. At 8 seconds, release Power only, keep holding Home for 5 more seconds
  4. Screen must stay completely black the whole time. Apple logo appearing = failed, just retry.

6 Safe check (no changes made)

./palera1n-linux-x86_64 -I

Expect to see:

Mode: DFU
ProductType: iPad5,3
DisplayName: iPad Air 2 (WiFi)

If it hangs or shows nothing, the iPad dropped out of DFU — redo step 5.

7 The real step

./palera1n-linux-x86_64 -p
  • May take 2–3 tries — this is normal, this exploit is a precise timing trick
  • On error/failure: unplug cable, wait 2 sec, replug, redo step 5, run -p again
  • Success looks like: a wall of checkra1n/Pongo text, ending in a new prompt that just sits there waiting. Don't type anything else into it yet.

8 When you get there

Screenshot or photograph whatever the terminal shows — success or the exact error text after several tries. Then boot back to Windows (top-right power icon → Restart, remove the USB when prompted). Come back to the same chat and show what you got.

Don't type any command beyond what's listed here. If anything looks different from this description, stop and describe exactly what you see instead of guessing.
